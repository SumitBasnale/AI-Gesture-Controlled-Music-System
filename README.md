# 🎵 AI-Based Hand Gesture Controlled Music System

A real-time music control system that allows users to control local music playback using hand gestures through a webcam.

## 🚀 Features

- ✊ **Fist** → Play / Pause music
- 👉 **Swipe Right** → Next track
- 👈 **Swipe Left** → Previous track
- ✌️ **Two Fingers** → Volume control
- 🎥 Real-time hand gesture detection using webcam
- 🎵 Local music playback

## 🛠️ Technologies Used

- **Python**
- **OpenCV** – Webcam and image processing
- **MediaPipe** – Hand landmark detection
- **Pygame** – Music playback
- **PyCaw** – Volume control
- **NumPy**
